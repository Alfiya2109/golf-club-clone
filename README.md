# ⛳ Sidcup Family Golf Club Clone - Luxury Recreation UI

> 🔗 **Live Website Demo**: [https://golf-club-clone.vercel.app](https://golf-club-clone.vercel.app)  
> 🛠️ **Tech Stack**: HTML5, CSS3, Vanilla JavaScript, GSAP (GreenSock), GSAP ScrollTrigger

---

## 🌟 Overview
A pixel-perfect, award-inspired recreation of the luxury **Sidcup Family Golf Club** website. This project showcases advanced frontend animation techniques, physics-based custom cursors, dynamic navbar transformations, and smooth scroll effects.

---

## 🚀 Key Features

- 🎯 **Custom Physics Cursor**: Dual-ring trailing cursor with fluid magnetic lag effect that expands on interactive elements.
- 🎬 **Looping Ambient Background Video**: Fullscreen high-definition video backdrop with dark overlay gradients.
- 📜 **GSAP ScrollTrigger Transitions**: Dynamic navigation bar color shifting and blur effect triggered on scroll threshold.
- 🃏 **Interactive Tilt Cards & Sliders**: 3D card tilt effects on hover and luxury typography layouts.
- 📱 **Fully Responsive**: Adapts seamlessly to ultra-wide desktop monitors, laptops, tablets, and smartphones.
